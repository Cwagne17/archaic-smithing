# Archaic Smithing Website - AI Agent Guide

## Project Overview

This repository contains the source code for the **Archaic Smithing** website, a client-facing platform for showcasing handcrafted jewelry and leatherwork by Camden Ailinger.  
The site provides a clean, gallery-driven browsing experience and a direct channel for custom work requests.

---

## Technology Stack

- **Next.js**: React framework for server-side rendering and static site generation.
- **TailwindCSS**: Utility-first CSS framework for consistent, responsive styling.
- **TypeScript**: Strong typing and maintainability for frontend logic.
- **Form Handling**: Next.js API routes for submission processing.
- **Image Management**: Gallery images stored and served via Next.js image optimization.

---

## Functional Requirements

1. **Image Galleries**

   - Sorted by work type: **Jewelry** and **Leather**.
   - Clicking an image opens a detail view with:
     - Item description
     - Additional images (if available)

2. **Custom Work Requests**

   - Form fields:
     - Title
     - Name (required)
     - Email (required)
     - Description
     - Optional file upload (image/document reference)
   - Submissions stored for **admin review**.

3. **Admin Features**
   - Add/manage galleries and images.
   - Review and manage incoming custom requests.

---

## Design Guidelines

- **Branding**: Align with the **Archaic Smithing logo** (rope circle + crow).
- **Color Palette**:
  - Base: grayscale/neutral background
  - Accent: **Red from the logo** (primary buttons, links, highlights)
  - Typography: clean serif/sans-serif pairing, black/gray body text
